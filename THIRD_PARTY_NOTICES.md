## Evaluated nuclear data

The ENDF-formatted cross-section files under `data/ENDF_crosssections/` were
obtained from the IAEA Nuclear Data Services, Evaluated Nuclear Data File
(ENDF):

<https://nds.iaea.org/exfor/endf.htm>

The evaluation metadata embedded in each file has been retained. In
particular, the D-T files identify the `ENDF/B-VI MOD 2 Evaluation`, January
1995, G. Hale (LANL). The ENDF data files are not relicensed under the MIT
License; users should consult the original source and file metadata for the
applicable data terms and citations.
